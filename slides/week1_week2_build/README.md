# Week 1 + Week 2 update deck

`slides/week1_week2_update.pptx` (8 slides): Week 1 proposal, dataset and baselines, the Week 2 updates (only the items
planned in Week 1), and the Week 3 plan. Built with pptxgenjs:

    npm install pptxgenjs@3.12.0
    node build_deck.js ../week1_week2_update.pptx <path-to-pptx-skill>/scripts/apply_theme.js

`att_*.png` are crops of `results/attention/<patient>.png` (Week 2 ABMIL attention maps).
Numbers are as of the end of Week 2 (ABMIL on the earlier folds; the fixed-split ABMIL rerun is a Week 3 item).
